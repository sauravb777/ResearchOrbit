# ResearchPilot Next.js frontend

This is the submission frontend for ResearchPilot. It is a client-side React/Next.js app that talks to the FastAPI backend.

## Development

```bash
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_URL` if the backend is not at `http://127.0.0.1:8000/api`.

The original Vite frontend remains in `frontend/` for backward compatibility. `frontend-next/` is the recommended submission frontend.
